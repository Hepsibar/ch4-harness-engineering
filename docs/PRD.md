# PRD: YT Next Advisor

## 목표
내 유튜브 채널을 분석해 "지금 어떤 콘텐츠를 하고 있는지"를 파악하고, 같은 분야에서 요즘 바이럴한 콘텐츠를 근거로 다음에 만들 콘텐츠를 추천한다.

## 사용자
자기 채널의 다음 콘텐츠 방향을 고민하는 1인 유튜브 크리에이터 (본인).

## 핵심 기능
1. **채널 입력 & 수집** — 채널 핸들/URL/ID를 입력하면 최근 영상(제목·설명·태그·조회수)을 수집한다.
2. **채널 분석** — 수집한 영상을 바탕으로 이 채널의 주제/포맷/톤/니치를 요약한다 (Claude).
3. **바이럴 탐색 & 다음 콘텐츠 추천** — 분석된 니치 기준으로 요즘 인기/급상승하는 유사 콘텐츠를 찾고, 그걸 근거로 다음 콘텐츠 아이디어를 추천한다 (YouTube 검색 + Claude).

## MVP 제외 사항
- 로그인/인증, 사용자 계정, DB 저장 (결과는 요청 시 즉석 생성, 영속 저장 없음)
- 내 채널의 비공개 분석(시청 지속시간·이탈률 등 YouTube Analytics/OAuth) — 공개 Data API만 사용
- 썸네일 자동 생성, 스크립트 자동 작성, 예약 발행 등 제작/운영 기능

## 디자인
- 라이트 기본, 미니멀. 입력 한 칸 → 결과 한 화면(분석 요약 + 추천 카드 목록).
- 무채색 + 포인트 컬러 1가지. 과한 장식 없이 가독성 우선.
